# India Wild Explorer

A map of India's forests and the big animals. Click a state for forest cover and counts, or a pin to open a national park.

Double-click `Start India Wild Explorer.bat`. It opens the page in its own window, Edge if you have it, otherwise Chrome. You can also open `app/index.html`.

If Windows says it protected your PC, choose More info, then Run anyway. The file only opens the page.

It works offline. Fonts look a little better when you're online.

Forest figures are from the Forest Survey of India (ISFR 2021 and 2023). Animal counts are from NTCA and WII, Project Elephant, and the Gujarat and Assam forest departments. Park numbers are rounded.
